# OSINT Elite v2

GitHub Pages-ready static OSINT research dashboard.

### Важно про «поиск по всему интернету»
GitHub Pages — статический хостинг. JavaScript в браузере не может честно просканировать весь интернет. Поэтому эта версия создаёт параллельный набор ссылок на публичные поисковые системы и специализированные публичные источники.

Для настоящего агрегатора нужен backend/API-слой, который законно обращается к конкретным API. Не храните API-ключи в GitHub Pages JavaScript: любой посетитель сможет их увидеть.

### Поддерживаемые типы
phone, username, email, domain, IP, URL, plate, keyword.

### Публикация
Settings → Pages → Deploy from a branch → main → /(root).

Инструмент предназначен для законного анализа открытых источников и не предназначен для доступа к приватным аккаунтам, закрытым базам или обхода авторизации.
